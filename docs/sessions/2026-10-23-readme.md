# Apresentação do repositório

Autoria: Codex (OpenAI), 23/10/2026. Daniel pediu capturas do app e um README melhor para a página inicial. Especificou mostrar somente a interface, sem desenhos ou imagens geradas, e manter a pasta de desenvolvimento local atualizada.

README.md e LEIA-ME.md foram reorganizados com download em destaque, visão geral dos recursos, capturas da interface, instalação, formatos de arquivo e ajuda. As instruções técnicas foram preservadas e atualizadas em docs/development.md.

As seis imagens finais foram capturadas diretamente do frontend atual em perfis isolados de navegador headless, em inglês e português, sem controlar janelas do desktop. A interface não foi redesenhada. O canvas foi verificado vazio, sem estado sujo e com zero passos de histórico. As imagens dos controles são capturas diretas dos painéis de ajustes.

Foram conferidos os links locais, o carregamento das imagens, a renderização desktop e a largura em uma tela de 390 px. Apenas documentação e imagens foram publicadas na main; o app e a release 0.3.1 não foram alterados. Os arquivos estão na cópia de desenvolvimento Doodle-Dev/Doodle, com as alterações locais anteriores preservadas.
